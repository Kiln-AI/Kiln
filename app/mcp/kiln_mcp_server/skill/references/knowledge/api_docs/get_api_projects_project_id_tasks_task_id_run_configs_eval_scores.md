# List Eval Scores For All Run Configs

**GET /api/projects/{project_id}/tasks/{task_id}/run_configs/eval_scores**

**Tags:** Run Configs

Eval scores for every run config of the task, keyed by run config id. Each value matches the per-run-config eval_scores endpoint.

## Request

### Path Parameters

|Name|Type|Required|Description|
|-|-|-|-|
|project_id|string|Yes|The unique identifier of the project.|
|task_id|string|Yes|The unique identifier of the task within the project.|

## Responses

### 200 OK

Successful Response

Validation Error

|-|-|-|
|detail|array of ValidationError||
