# Generate Repair

**POST /api/projects/{project_id}/tasks/{task_id}/runs/{run_id}/generate_repair**

**Tags:** Runs

Invoke an AI model to generate a repaired output for a task run based on evaluator feedback. Returns the repair as a new TaskRun without persisting it.

## Request

### Path Parameters

|Name|Type|Required|Description|
|-|-|-|-|
|project_id|string|Yes|The unique identifier of the project.|
|task_id|string|Yes|The unique identifier of the task within the project.|
|run_id|string|Yes|The unique identifier of the task run.|

### Request Body

**Content Type:** `application/json`

|Field|Type|Required|Description|
|-|-|-|-|
|evaluator_feedback|string|Yes|Feedback from an evaluator on how to repair the task run.|
|model_name|one of: string or null|No|Optional override for the model used to generate the repair. When omitted, the model from the original run's source properties is used.|
|provider|one of: string or null|No|Optional override for the model provider used to generate the repair. Must be set together with model_name.|

### Usage

Token usage, cost, and aggregate LLM latency for a per-run accumulator.

Extends :class:`MessageUsage` with ``total_llm_latency_ms``, which is
only meaningful while a single run is in flight (its model calls run
sequentially in real time). For per-message records and full-trace
sums use :class:`MessageUsage` — those values would mix latencies
from different points in time, so the field doesn't apply.

|Field|Type|Required|Description|
|-|-|-|-|
|input_tokens|one of: integer or null|No|The number of input tokens used.|
|output_tokens|one of: integer or null|No|The number of output tokens used.|
|total_tokens|one of: integer or null|No|The total number of tokens used.|
|cost|one of: number or null|No|The cost in US dollars, saved at runtime (prices can change over time).|
|cached_tokens|one of: integer or null|No|Number of tokens served from prompt cache. None if not reported.|
|cache_write_tokens|one of: integer or null|No|Number of input tokens written to the prompt cache, which providers bill above the normal input price. None if not reported.|
|total_llm_latency_ms|one of: integer or null|No|Total time spent waiting on LLM API calls in milliseconds. Sum of per-call latencies, excludes tool execution time.|

### MessageUsage

Token usage and cost for a single LLM call or a multi-message sum.

Carries only the fields that are meaningfully aggregatable across
messages: token counts and cost. Per-call latency lives on the
individual message's ``latency_ms`` field; aggregating it across the
full trace would mix latencies from different points in time, so
``MessageUsage`` does NOT carry ``total_llm_latency_ms``.

The :class:`Usage` subclass adds ``total_llm_latency_ms`` for the
in-flight per-run accumulator that tracks how long this run spent
waiting on LLM calls.

|Field|Type|Required|Description|
|-|-|-|-|
|input_tokens|one of: integer or null|No|The number of input tokens used.|
|output_tokens|one of: integer or null|No|The number of output tokens used.|
|total_tokens|one of: integer or null|No|The total number of tokens used.|
|cost|one of: number or null|No|The cost in US dollars, saved at runtime (prices can change over time).|
|cached_tokens|one of: integer or null|No|Number of tokens served from prompt cache. None if not reported.|
|cache_write_tokens|one of: integer or null|No|Number of input tokens written to the prompt cache, which providers bill above the normal input price. None if not reported.|

### OpenEnvEpisode

One reset-to-close run on an environment, recorded on the trace of the
task run that used it. The environment's tools ran inside the episode; any other tools
in the run config ran as themselves, outside the environment.

Persisted on `TaskRun.openenv_episode` so graders (including judges added later,
which reuse the same trace) can read what the run left behind. The live session is
closed when the episode ends; `final_state` is the durable record.

|Field|Type|Required|Description|
|-|-|-|-|
|reset.openenv_server_id|string|Yes|ID of the OpenEnv server to start the episode on. >=1 chars|
|reset.reset_kwargs|object|No|Keyword arguments for the environment's reset(), passed verbatim. Which keywords exist is the environment's business, e.g. which dataset or scenario to start from, a seed, a clock override.|
|episode_id|string|Yes|Kiln's id for this episode, passed to the environment's reset() as `episode_id`. >=1 chars|
|openenv_version|string|Yes|The environment's name@version as its server reported it when the episode started (not the version of the openenv package): what produced this state. Kiln trusts a version to be immutable. >=1 chars|
|reset_metadata|object|No|What the environment reported in the observation metadata when the episode was reset: facts about the starting state that judges may want, such as the scenario it started from or the clock it runs on.|
|final_state|one of: object or null|No|The environment's state() after generation, read when the episode ends. Whatever the environment chooses to report: a diff against its starting state, counters, an episode summary.|
