# Levers

A lever is one thing in the harness of a Kiln agent that can be changed, and
how to change it: what it is, the steps and the rules of the object, its
limits, and where to read more. A lever never says when or why to change it:
the playbooks, the smells and the techniques of
`references/improving_agents/index.md` say that.

The column "API docs" names the endpoint docs that the lever's steps use.
Read each one before you call its endpoint.
